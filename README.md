# Avora App Prototype

Interactive portfolio prototype for Avora, a premium health food app.

## Flow

- Native Android launcher splash
- Login / signup entry
- Three onboarding screens
- Welcome and product promise
- Taste and goal setup
- Personalized home dashboard
- Recipe detail with servings and save state
- Meal plan and grocery prompt
- Progress and insight screen

## Run

```bash
npm install
npm run dev
```

## Android

```bash
npm run android:sync
cd android
.\gradlew.bat assembleDebug
```

Install the APK from:

`android/app/build/outputs/apk/debug/app-debug.apk`

The app id is `app.avora.prototype`, and the launcher label is `Avora`.
